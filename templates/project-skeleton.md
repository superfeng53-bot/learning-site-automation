## Naming Conventions

| Slot | Example (shuangwei) | Rule |
|------|---------------------|------|
| `<pkg>` | `sww_api` | snake_case, suffix `_api`, derived from domain |
| `<svc>` | `sww_service` | same prefix as `<pkg>`, suffix `_service` |
| `<DOMAIN>` | `course` | the central business object (lesson, course, project, exercise) |
| binary name | `双卫网_04_22` | `<site-CJK-name>_<MM>_<DD>` |
| db file | `sww_service.db` | `<svc>.db` |
| Excel 账号模板 | `医博士账号模板.xlsx` | `<平台中文名>账号模板.xlsx`（Sheet/表头全中文，见 `excel-spec.md`） |
| cookies file | `cookies.json` | always plural even for one account |

Keep `<pkg>` short — it's typed in every `python -m <pkg>.cli_*` invocation.
